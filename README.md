# 🚀 RectaBags - Versión React + Vite

Este proyecto ha sido migrado de HTML/CSS/JS Vanilla a una arquitectura basada en componentes con **React** y **Vite**.

---

## 📋 Prerrequisitos

Para ejecutar este proyecto en tu computadora local, necesitas tener instalado **Node.js**.

### 1. Descargar e instalar Node.js
1. Visita el sitio web oficial: [nodejs.org](https://nodejs.org/)
2. Descarga e instala la versión **LTS** (Long Term Support).
3. Verifica la instalación abriendo tu terminal (`cmd`, PowerShell o Terminal) y ejecutando:
   ```bash
   node -v
   npm -v


🛠️ Cómo abrir y ejecutar el proyecto
Si acabas de clonar el repositorio o cambiaste a esta rama, ya no es necesario crear el proyecto desde cero (npm create vite@latest), pero sí debes instalar sus dependencias.

2. Abrir la terminal en la carpeta del proyecto
En Windows: Abre la carpeta del proyecto en el Explorador de Archivos, escribe cmd en la barra de direcciones superior y presiona Enter.

O usando comandos de navegación:
cd ruta/a/tu/repositorio/Rectabagsweb

3. Instalar las dependencias
Ejecuta el siguiente comando para descargar las librerías necesarias (react, bootstrap, etc.) declaradas en el package.json:
npm install

4. Iniciar el servidor de desarrollo
Una vez finalizada la instalación, inicia el servidor local con:
npm run dev
